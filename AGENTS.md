# Reglas del proyecto
- Aplicación estática: no exigir Node de servidor, cuenta, API o IA para funciones esenciales.
- Mobile-first, español, grafito + verde discreto, estilo táctico sobrio. Sin emblemas oficiales ni afiliación militar.
- Datos de salud, fotos e historial solo locales. No añadir telemetría sin consentimiento.
- No aumentar cargas por calendario; conservar historia por variante y unidades.
- No pérdida de grasa localizada, resultados garantizados ni diagnóstico de lesiones.
- Excluir pescado, marisco y verduras no aceptadas. Verduras toleradas: pepino, tomate, aguacate, patata, batata; frutas libres.
- Tolerancias y condiciones médicas requieren revisión explícita. Las cantidades son estimaciones, no dieta clínica.
- Temporizadores usan fechas límite; persistir cada transición relevante.
- Recursos esenciales locales con licencia válida. SVG de ejercicios originales; revisar biomecánica si se modifica el patrón.
- Mantener exportación/importación JSON y compatibilidad de esquema v1.
- Ejecutar npm test. No afirmar pruebas de navegador o dispositivo no realizadas.
- Actualizar cache version del service worker cuando cambien recursos publicados.
